# emmazhang.dev

Personal résumé site for Shuyang Zhang. Vue 3 + Vite, single-page.

See `DESIGN.md` for design decisions and open items.

## Develop

```bash
npm install
npm run dev   # http://localhost:5174
```

## Content

All copy lives in `src/data/resume.js` — edit that file, not the components.

## Image assets

- `src/assets/portraits/`: website portraits, including the transparent cutout.
- `src/assets/projects/`: project screenshots used by the website.
- `design/assets/originals/portraits/`: retained portrait sources and exports.
- `design/assets/originals/projects/`: original uploaded project screenshots.

Use descriptive filenames for new images and keep uploads out of the repository root.
